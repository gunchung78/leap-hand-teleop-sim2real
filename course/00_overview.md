# LEAP Hand 실습 과정 — 로봇 손 텔레오퍼레이션과 디지털 트윈

이 저장소의 Phase 0(관절 매핑)과 Phase 1(웹캠 텔레오퍼레이션 + ROS2 디지털 트윈)을 **따라 하면 같은 숫자가
나오는 실습 과정**으로 재배열한 것이다. 강화학습(Phase 2)은 다루지 않는다.

교재의 원칙은 저장소의 원칙과 같다: **말이 아니라 측정으로 확인한다.** 모든 단원은 "실행 → 숫자 → 해석" 으로 끝난다.

## 대상과 준비물

- 대상: 파이썬과 ROS2 기초(노드·토픽·런치)는 아는데 로봇 손은 처음인 사람.
- 준비물: Ubuntu 22.04, 웹캠, (선택) LEAP Hand v1 **Lite** + U2D2. **실기가 없어도 1~7단원은 시뮬로 끝까지 간다.**
  실기 단원은 🤖 표시.
- 환경 구성: **`docs/setup.md`** 그대로 (conda `leap-hand`, `pip install -e .`, third_party 클론, ROS2 빌드). 강화학습용 `leap-mjx` 는 이 과정에선 불필요.

## 학습 목표 (과정 끝에 할 수 있는 것)

1. 시뮬 모델과 실기 사이의 관절 순서/0점 차이를 **스스로 찾아내고 수치로 검증**한다.
2. 웹캠 손 추적을 로봇 손 관절각으로 바꾸는 파이프라인을 ROS2 노드로 만들고, **지연·추종·떨림을 숫자로** 잰다.
3. 실기를 안전하게 붙인다 — 전류 한계, 데드맨, 시작 자세, 동결과 해제.
4. "로봇이 이상하게 움직인다"를 **원인 후보로 쪼개고 하나씩 배제**한다.
